A tiny program for the make.fun bounty
[The Best Meal You Ever Had](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85).

Running `main.ts` writes a single sentence, at most 200 characters, about
the best meal ever had to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## Run it

```sh
node main.ts
```
